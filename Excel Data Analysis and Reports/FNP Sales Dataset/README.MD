# 📊 Ferns and Petals Sales Analysis Dashboard

## Overview
This project is an Excel-based sales analysis dashboard built using the **Ferns and Petals (FNP) Sales Dataset**.

The objective of this project is to analyze sales trends, customer behavior, delivery performance, and product popularity across multiple occasions such as:
- Diwali
- Holi
- Raksha Bandhan
- Valentine's Day
- Birthdays
- Anniversaries

---

## Project Objectives
The dashboard answers the following business questions:

1. Total Revenue Analysis  
2. Average Order and Delivery Time  
3. Monthly Sales Performance (2023)  
4. Top Products by Revenue  
5. Customer Spending Analysis  
6. Sales Performance of Top 5 Products  
7. Top 10 Cities by Number of Orders  
8. Order Quantity vs Delivery Time  
9. Revenue Comparison Between Occasions  
10. Product Popularity by Occasion
