# 📊 E-Commerce Sales Dashboard

## Overview
This project is an **Excel-based E-Commerce Sales Dashboard** created to analyze sales performance, profitability, customer behavior, and product trends.

The dashboard provides interactive insights into business performance and helps in identifying high-performing categories, products, and regions.

---

## Project Objectives
This dashboard focuses on analyzing:

1. Total Sales Analysis  
2. Revenue Performance  
3. Profit Analysis  
4. Sales Trends Over Time  
5. Category and Sub-Category Performance  
6. Regional Sales Analysis  
7. Customer Purchase Trends  
8. Top Performing Products  
9. Sales by Customer Segment  

---

## Dashboard Features
- Interactive Dashboard  
- KPI Cards  
- Pivot Tables  
- Pivot Charts  
- Slicers for filtering  
- Dynamic sales visualizations  

---

## Tools Used
- Microsoft Excel  
- Pivot Tables  
- Pivot Charts  
- Conditional Formatting  
- Dashboard Design Techniques  

---

## Key Insights
- Identified top-performing products and categories  
- Analyzed regional sales contribution  
- Compared profit and revenue trends  
- Tracked sales performance over time  
- Studied customer purchasing behavior
