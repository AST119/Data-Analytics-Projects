# HR Analytics Dashboard - Power BI

## 📌 Project Overview
This project focuses on building an **HR Analytics Dashboard** in Power BI to analyze employee attrition patterns and identify the major reasons behind employees leaving the company.

The dashboard helps HR teams and management make data-driven decisions to improve employee retention and workplace satisfaction.

---

## 🎯 Objective
The main objective of this dashboard is to:

- Identify key factors contributing to employee attrition
- Analyze workforce demographics and distribution
- Understand patterns related to job role, salary, age, education, and work environment
- Support better HR decision-making through interactive visual insights

---

## 🛠️ Data Preparation & Transformation
Before dashboard creation, the dataset was cleaned and transformed to ensure accuracy and consistency.

### Steps performed:
- Data transformation using **Power Query**
- Corrected and standardized data types/formats
- Removed duplicate records
- Handled null/missing values
- Performed data distribution analysis for key columns
- Cleaned and structured dataset for reporting

---

## 📊 Dashboard Features
The dashboard includes:

- Employee attrition overview
- Department-wise attrition analysis
- Age group distribution
- Salary slab analysis
- Education field insights
- Job role analysis
- Gender distribution
- Interactive filters and slicers for better exploration

---

## 🎨 Custom Design
To enhance dashboard appearance and user experience:

- Created and applied a custom **theme.json** file
- Used a consistent color palette for better readability
- Designed clean KPI cards and charts layout

---

## 🧰 Tools Used
- **Power BI**
- **Power Query**
